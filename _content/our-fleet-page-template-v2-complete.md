## 9) Image Handling Rules (for implementation)

1. Ignore system artifacts starting with `._`.
2. Prefer non-`._` files only for web gallery.
3. Per vessel image recommendation:
   - 1 cover image
   - 3 to 8 gallery images
4. Export image variants:
   - Thumbnail
   - Web display size
   - Original download (optional)
5. Alt text format:
   - `[Vessel Name] - [View/Context]`
   - Example: `Mega Success - sea trial side view`
